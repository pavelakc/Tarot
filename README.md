# Таро Расклад

Приложение для раскладов таро: колода Райдера–Уэйта–Смит (1909), онлайн-расклад или ввод карт из своей колоды, восемь раскладов, полный разбор через Claude, дневник и кнопка «Поделиться».

Открыть: страница GitHub Pages этого репозитория. На iPhone: Safari → «Поделиться» → «На экран Домой», и приложение будет открываться как обычное.

Полный разбор вне Claude работает через ваш ключ Anthropic API (вводится в «Настройках разбора», хранится только в браузере). Без ключа приложение копирует готовый запрос для приложения Claude.

Изображения карт: Памела Колман Смит, 1909, общественное достояние в США. Сканы: steve-p.org, через github.com/mixvlad/TarotCards.
